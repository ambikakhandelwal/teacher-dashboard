Teacher Dashboard — An intuitive, responsive dashboard that helps teachers monitor student progress, view game-based performance, and generate personalized feedback and learning plans.

It aggregates class and student-level stats into clean cards and charts (Chart.js), provides detailed student views with subject mastery and game analytics, and includes AI-powered buttons to create tailored feedback/learning plans (uses a proxied Gemini API in production). Built with plain HTML, lightweight CSS, and vanilla JavaScript — mock data included for quick testing and easy integration with any backend.
